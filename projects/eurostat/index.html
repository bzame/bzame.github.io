Eurostat Multi-MNO: testing a European pipeline on an operator's data

Testing the methods Eurostat is developing for official statistics from mobile network data, inside a mobile operator's cloud.

Client
Eurostat (Multi-MNO project)
Partners
Fastweb + Vodafone, Positium, GOPA
My role
Project leader
Data
Mobile network data (Fastweb + Vodafone)

Motion Analytica's part of a Eurostat project; there is no Motion Analytica case study. The project's public pages are on Eurostat's CROS portal.

The Multi-MNO project on Eurostat's CROS portal

The question

Eurostat’s Multi-MNO project is developing a common method, with open software, for producing official statistics from the data of several mobile network operators across Europe. Before such a method can be used, it has to run on real operator data, inside the operator’s own systems, where the data never leave.

What I did

  • Coordinated the project’s developers (Positium and GOPA) with Motion Analytica’s data engineers to test the general solution in Fastweb’s cloud environment.
  • Coordinated Motion Analytica’s and Fastweb’s data engineers to get what the tests needed, such as cluster images with the right libraries.
  • Contributed, in a small part, to the public report.

The testing took place in 2024; the report was published in 2025.

What I remember

Seeing our experience with Istat lead to European work on mobile network data for official statistics: both Multi-MNO and the related MNO-MINDS project were coordinated by the Istat researchers we had worked with. I later presented our tourism work at the MNO-MINDS final conference.
